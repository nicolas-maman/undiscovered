# Data licence

The data this project publishes (candidate pairs, backtest results,
aggregated ratings and model accuracy) is dedicated to the public domain
under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

It is derived from [OpenAlex](https://openalex.org), which is itself CC0.
Credit is not required by either licence, but it is appreciated: please cite
OpenAlex (Priem, Piwowar & Orr, 2022) and this project (see
[CITATION.cff](CITATION.cff)).

Contributions submitted to the project (work results, ratings, bridge reports)
are published under the same CC0 dedication; the issue forms say so before a
contributor submits.
